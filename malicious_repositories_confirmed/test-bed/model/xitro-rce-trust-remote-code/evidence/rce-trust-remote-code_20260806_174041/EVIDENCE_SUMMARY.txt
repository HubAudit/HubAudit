EVIDENCE SUMMARY (redacted)
============================
Case directory: rce-trust-remote-code_20260806_174041

The raw network capture / receiver log for this run contained personal data (a real
username, home-directory path, and/or real IP addresses) belonging to the person who ran
the test, picked up incidentally because these files record exploitation of the target
repo against a real sandbox account. The raw files (capture.pcap, nc_received.log) have been
removed from this release; this summary replaces them so the finding stays documented.

What happened in this run:
Command-execution PoC. Two POST /exfil calls to 127.0.0.1:8080 (User-Agent:
python-requests/2.34.2) carrying the output of a shell id command run by the PoC
(uid/gid/group-membership line for the sandbox account). Discloses the real OS
username/uid/gid/group membership of the sandbox account, not an IP address or a secret.
